   # 🍕 Pizza Sales Data Analysis

## 📌 Project Overview

This project analyzes one year of pizza sales data to uncover valuable business insights that can help improve sales performance, optimize operations, and support data-driven decision-making.

Using Python, I cleaned, merged, transformed, and analyzed four related datasets to answer key business questions regarding revenue, sales trends, customer purchasing behavior, product performance, and peak ordering hours.

---

## 🎯 Project Objectives

This project aims to:

- Calculate total revenue generated.
- Determine the total number of pizzas sold.
- Identify the total number of customer orders.
- Analyze average pizza prices.
- Discover peak sales hours.
- Evaluate pizza category performance.
- Generate actionable business insights through data visualization.

---

## 📊 Dataset

The project uses four datasets:

| Dataset | Description |
|---------|-------------|
| **orders.csv** | Customer order information |
| **order_details.csv** | Quantity of pizzas ordered |
| **pizzas.csv** | Pizza sizes and prices |
| **pizza_types.csv** | Pizza names, categories, and ingredients |

## 🔄 Data Preparation

The following preprocessing steps were carried out:

- Merged datasets using common keys.
- Converted date and time columns into appropriate datetime formats.

  - Hour
  - Day Name
  - Month
- Checked for missing values.
- Verified data types.
- Prepared the dataset for exploratory data analysis.

## 📈 Business Questions Answered

This project answers the following business questions:

- What is the total revenue generated?
- How many pizzas were sold?
- How many customer orders were placed?
- How many pizza varieties are available?
- What is the average pizza price?
- What are the busiest ordering hours?
- Which pizza categories generate the most revenue?
- Which pizzas perform best?

---

## 💡 Key Insights

- Total Revenue: **$817,860.05**
- Total Pizzas Sold: **49,574**
- Total Orders: **21,350**
- Pizza Varieties: **32**
- Average Pizza Price: **$16.50**
- Peak ordering periods occurred during lunch and dinner hours.
- The restaurant offers four pizza categories:
  - Classic
  - Chicken
  - Supreme
  - Veggie
